# Inspiration

One folder per source, created by `npm run design:inspect -- <url|image>`:

```
inspiration/
  linear-app/            summary.md, inspect.json, above-fold.png, full.png, mobile.png
  poster/                summary.md, inspect.json, poster.png
  brief.md               the synthesis: what we take from each source and why
```

`brief.md` is the bridge from references to tokens. Keep it short:

- **Take:** specific, transferable qualities ("warm off-white canvas", "one saturated accent", "tight display tracking").
- **Leave:** what belongs to the reference's brand (their exact colors, logo, illustration style).
- **Tension:** where sources disagree and which one wins for this product.
